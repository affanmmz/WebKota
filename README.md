# Web Informasi Kota Bogor 🌧️

**Web Informasi Kota Bogor** adalah proyek halaman web landing/informasi sederhana yang dibuat sebagai pemenuhan **Submission 1 Kelas Pemrograman Web Dasar Dicoding**. Website ini menyajikan informasi umum mengenai Kota Bogor, mulai dari letak geografis, tempat wisata populer, hingga profil singkat kota.

---

## 🚀 Fitur Utama

- **Navigasi Menu:** Pintasan navigasi yang memudahkan pengguna berpindah ke bagian informasi Geografis, Wisata, atau Profil Dicoding pembuat[cite: 2].
- **Informasi Geografis & Wisata:** Penjelasan detail mengenai kondisi geografis Kota Bogor serta destinasi wisata ikonik seperti Kebun Raya Bogor[cite: 2].
- **Bilah Samping (Aside) Informasi:** Tabel ringkasan fakta penting Kota Bogor (Negara, Hari Jadi, Jumlah Populasi, Bahasa Daerah, dan Kode Telepon)[cite: 2].
- **Tata Letak Semantic HTML:** Menggunakan elemen-elemen HTML5 seperti `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, dan `<footer>`[cite: 2].

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur dokumen dan konten web[cite: 2].
- **CSS3:** Penataan gaya tampilan dan tata letak (`asset/css/style.css`)[cite: 2].
- **Google Fonts:** Menggunakan font *Poppins*, *Quicksand*, dan *Space Mono*[cite: 2].
